## 当前工程状态

- MCU：STM32F722，主频 216 MHz
- USB：CDC 虚拟串口，支持非阻塞发送
- 陀螺仪：LSM6DSK320X，SPI1 + FIFO + DMA，1 kHz 后台采样
- 姿态：Mahony 四元数，当前四元数输出关闭
- 电源检测：PC1 电流、PC2 电池电压，当前电压电流输出关闭
- 气压计：DPS310，I2C1，气压/温度连续测量
- 当前 VOFA+ 输出：

```text
气压(Pa),温度(°C),相对高度(m)
```

- 最新 Keil 全量编译：`0 Error(s), 0 Warning(s)`
- 最新映像：`Code=30354`、`RO=966`、`RW=580`、`ZI=10804`
