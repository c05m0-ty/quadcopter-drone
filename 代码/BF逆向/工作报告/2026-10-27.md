# 2026-10-27 工作日报

## 今日目标

完成系统基础配置和 USB CDC 虚拟串口。

## 完成内容

### 系统时钟

- 使用 8 MHz HSE。
- PLLM=8、PLLN=432、PLLP=2，SYSCLK 配置为 216 MHz。
- APB1 为 54 MHz，APB2 为 108 MHz。
- 使用 PLLSAI 产生 USB 所需 48 MHz 时钟。
- Flash 设置为 7 个等待周期并启用 Over-Drive。

### 调试与故障处理

- 将 `PA15` 配置为板载 LED 输出。
- 加入启动阶段闪烁诊断。
- 启用 MemManage、BusFault 和 UsageFault。
- 异常时通过 LED 闪烁输出故障地址，便于没有 ST-Link 时定位。

### USB CDC

- 加入 STM32 USB Device Core、CDC 类和板级 USB 配置。
- 实现 CDC 虚拟串口初始化和收发接口。
- 修复 USB 描述符读取芯片 UID 时触发 BusFault 的问题。
- 改为固定序列号，USB 设备可以稳定枚举。

## 实板验证

- Windows 能识别 CDC 虚拟串口。
- 串口可以打开、发送和接收。
- USB 枚举不再出现 Code 10 或 IO 超时。
