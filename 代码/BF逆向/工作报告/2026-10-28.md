# 2026-10-28 工作日报

## 今日目标

完成 LSM6DSK320X 六轴传感器、FIFO、SPI DMA 和姿态输出链路。

## 完成内容

### 传感器识别与配置

- 通过 SPI1 读取 `WHO_AM_I`，确认芯片 ID 为 `0x75`。
- 使用 SPI Mode 3，时钟约 844 kHz。
- 配置陀螺仪 ±2000 dps、加速度计 ±16 g。
- 陀螺仪和加速度计输出率均配置为 1 kHz。
- 启用 BDU、地址自动递增和硬件滤波。

### FIFO 与中断

- 将传感器 INT1 配置为 FIFO 阈值/溢出中断。
- 将 PC3 配置为上升沿 EXTI。
- FIFO 水位设置为 16 条记录，单次最多读取 32 条。
- USB 连接 5 秒后才启动 FIFO，避免等待上位机期间溢出。

### SPI DMA

- SPI1 RX 使用 DMA2 Stream0/Channel3。
- SPI1 TX 使用 DMA2 Stream3/Channel3。
- DMA 缓冲区按 32 字节对齐。
- 处理 Cortex-M7 D-Cache clean/invalidate。
- DMA 超过 5 ms 未完成时自动中止。

### 姿态计算

- 使用 Mahony 六轴融合。
- 内部姿态改为四元数，避免欧拉角万向锁。
- 四元数归零使用当前姿态乘零点共轭。
- 通过 USB 以约 20 Hz 输出 `w,x,y,z` 到 VOFA+ FireWater。

## 实板验证

- 六轴数据随姿态变化。
- 静止时加速度模长接近 1 g。
- FIFO、PC3 中断和 SPI DMA 均能正常工作。
- 四元数模式通过 Pitch 约 90° 时未再出现欧拉角的轴翻转问题。

## 当前限制

- 没有磁力计，Yaw 仍无绝对航向参考。
- 快速运动后 Yaw 仍可能累计漂移。
